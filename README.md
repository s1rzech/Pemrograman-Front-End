# Front-End Programming

Repository ini berisi kumpulan latihan dan proyek selama mempelajari mata kuliah **Pemrograman Front-End**. Setiap latihan menjadi bagian dari proses belajar membangun halaman web menggunakan HTML dan CSS.

## Isi Repository

### 1. HTML Practice
Kumpulan latihan HTML untuk memahami struktur dasar halaman web, penggunaan elemen HTML, heading, paragraf, tautan, gambar, daftar, formulir, dan elemen lainnya sesuai materi yang dipelajari.

### 2. Minimalist Portfolio
Website portofolio pribadi dengan pendekatan desain minimalis. Fokusnya adalah tata letak yang rapi, tipografi yang jelas, ruang kosong yang seimbang, dan navigasi yang mudah digunakan.

### 3. Neo-Brutalism Portfolio
Versi alternatif website portofolio dengan gaya **Neo-Brutalism**, menggunakan garis tebal, kontras warna yang kuat, bentuk geometris, serta bayangan tegas untuk menghasilkan tampilan yang ekspresif.

## Teknologi

- HTML5
- CSS3

Repository ini dibuat sebagai sarana latihan dan dokumentasi perkembangan belajar front-end. Struktur folder atau isi proyek dapat bertambah seiring proses pembelajaran.

## Menjalankan Proyek

1. Clone atau download repository ini.
2. Buka folder proyek yang ingin dijalankan.
3. Buka file `index.html` di browser.
4. Untuk pengembangan melalui Visual Studio Code, kamu dapat menggunakan ekstensi Live Server jika diperlukan.

> Catatan: Nama file dan folder dapat berbeda sesuai susunan yang digunakan di repository. Pastikan membuka `index.html` dari proyek yang ingin dilihat.

## Tujuan Pembelajaran

- Memahami struktur dokumen HTML.
- Menerapkan CSS untuk mengatur tampilan halaman web.
- Mempelajari perbedaan pendekatan desain minimalis dan Neo-Brutalism.
- Melatih konsistensi struktur kode dan dokumentasi proyek.
